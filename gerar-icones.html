📋 Como usar no GitHub:

  1. Clique em "Baixar TODOS os ícones"
  2. Extraia o arquivo ZIP
  3. Crie uma pasta icons/ na raiz do seu projeto
  4. Coloque todos os ícones na pasta icons/
  5. Faça commit e push para o GitHub
